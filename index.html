Code Abstract Results

Abstract

Video games have become a cornerstone of entertainment in most cultures. They remain the favorite pastime with more than 212 Million people playing regularly in the United States [1]. This extends to an even more pronounced trend globally, where the number explodes to 3.22 billion [2]. With the speedy development of artificial intelligence (AI), the intersection of AI and modern video games has become increasingly prevalent. While AI has been around for a while, the use of Reinforcement Learning (RL)is still an emerging trend within video games. As illustrated in figure 1,RL allows for a model or agent to obtain observations from their environment, select and action, then receive a reward that determines how useful the action was. This iterative process allows for an agent to effectively self-learn [3]. Our project aims to make use of an RL agent to learn the environment of the video games based on a reward system to improve its playing skills overtime. The amount of time needed for an agent to beat the game will indicate to us the difficulty of the game, determining if it is appropriate to release to the public.

Setup

A traditional Unreal Engine AI behavior tree was implemented in C++ to control the boss character as a rule-based baseline. Meanwhile, the Learning Agents framework was used to define the observation space, environment, and reward system for a reinforcement learning agent. This unified setup allowed for a controlled comparison between rule-based and learning-based approaches within the same interactive environment.

Implementations

Each character action was encapsulated as a C++ function and exposed to Blueprint, providing the Learning Agents plugin with a structured interface for character control.This design separates low-level implementation from high-level decision making, allowing the agent to interact with the environment through a well-defined action space.

Observation & Reward Design

We design the observation space and reward system to guide the agent's learning process. The observation space defines how the agent perceives the environment, while the reward system provides feedback to encourage effective behaviors. A detailed overview is provided in the following document.
